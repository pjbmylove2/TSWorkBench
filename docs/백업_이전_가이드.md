# 백업 · 다른 PC로 옮기기

> **한 줄 요약**: 다른 PC에서 똑같이 쓰려면 **① 데이터 폴더 ② 코드 폴더 ③ TS WorkBench 프로그램 폴더** 세 개를 복사하면 됩니다. NAS(`\\10.101.0.80\ts팀\박종부\TSWork`)에 있는 것은 그대로 두면 됩니다.

---

## 1. 내 작업이 있는 곳 (한눈에)

| 무엇 | 어디 (지금 설정) | 다른 PC로 옮길 때 |
| --- | --- | --- |
| **업무 데이터** — 업무 카드, 첨부 사진·로그, 보고서, 설정, 기준 정보, 프로그램 목록, 버전·설치 기록 | 데이터 폴더 `D:\박종부\TS업무` | **폴더째 복사 (가장 중요)** |
| **코드** — 프로그램별 소스 (Git 저장소) | 코드 폴더 `D:\박종부\00.Source\…` | 폴더째 복사 (또는 NAS에서 받기, 3장) |
| **TS WorkBench 프로그램** | VS2022에서 Release로 빌드한 `src\TSWorkBench\bin\Release` | 폴더째 복사 (`Help`·`Templates` 폴더 포함) |
| 코드 백업 | NAS `…\TSWork\Git\프로그램.git` | 그대로 (NAS) |
| 배포본 (실행 파일·소스·매뉴얼 zip) | NAS `…\TSWork\Releases` | 그대로 (NAS) |
| 업무 기록 자동 백업 zip | NAS `…\TSWork\Backups` | 그대로 (NAS) |
| 이 PC만의 기억 (마지막 데이터 폴더 위치, 오류 기록) | `%AppData%\TSWorkBench` | 옮기지 않아도 됨 |
| Git 사용자 이름·메일 | 각 PC의 Git 설정 | 새 PC의 VS2022에서 한 번 입력 |

데이터 폴더 안을 자세히 보면 이렇습니다 (자세한 설명은 사용설명서 2장).

```
D:\박종부\TS업무\
  settings.json    설정 (이름·회사·배포본 보관소·자동 백업 폴더·코드 폴더 위치)
  masters.json     기준 정보 (고객사·사이트·설비·시스템, 체크리스트)
  programs.json    등록한 프로그램 (코드 폴더·빌드 폴더·NAS 코드 백업 위치)

  Releases\        버전·설치 기록 (어느 사이트에 몇 버전)
  Reports\         주간·월간 보고, 엑셀 업무대장
  Templates\       보고서 양식
  Trash\           휴지통 (지운 업무·프로그램 기록)
```

## 2. 다른 PC로 옮기기

### 2.1 지금 PC에서 (옮기기 전)

1. VS2022에서 고친 코드를 모두 **커밋**합니다.
2. TS WorkBench › **프로그램 · 배포** › `프로그램 · 코드` 보기에서 코드 상태가 모두 **✔ 깨끗함**인지 보고, **NAS 코드 백업**을 한 번 누릅니다.
3. TS WorkBench를 **끕니다** (열려 있는 업무 카드는 저장하고 닫기).
4. 아래 세 폴더를 USB나 NAS로 복사합니다.
   - 데이터 폴더 `D:\박종부\TS업무` (통째로)
   - 코드 폴더 `D:\박종부\00.Source` (통째로. 3장처럼 NAS에서 받을 거면 생략 가능)
   - TS WorkBench 프로그램 폴더 (`bin\Release` 통째로)

### 2.2 새 PC에서

1. **VS2022**를 설치합니다 (Git 포함). VS2022가 없으면 **Git for Windows**만 있어도 TS WorkBench의 버전 관리는 됩니다.
2. 복사한 폴더를 **예전과 같은 경로**에 붙여 넣습니다. 같은 경로면 고칠 것이 없습니다.
   - `D:\박종부\TS업무`, `D:\박종부\00.Source`
   - 프로그램 폴더는 아무 곳이나 괜찮습니다 (예: `D:\박종부\TSWorkBench_App`).
3. NAS가 열리는지 확인합니다: 탐색기 주소창에 `\\10.101.0.80\ts팀\박종부\TSWork` 입력. 로그인 창이 뜨면 **자격 증명 저장**에 체크합니다.
4. `TSWorkBench.exe` 실행 → 데이터 폴더를 고르는 창에서 `D:\박종부\TS업무`를 고릅니다.
5. VS2022 › **Git › 설정 › Git 전역 설정**에서 사용자 이름·메일을 넣습니다 (커밋에 남는 이름).
6. **프로그램 · 배포** › `프로그램 · 코드` 보기에서 코드 상태가 예전과 같은지 보고, **NAS 코드 백업**을 한 번 누릅니다.
   - 새 PC에서 NAS 저장소를 "믿을 곳"으로 등록하는 것까지 자동으로 합니다.

### 2.3 경로가 달라졌을 때 (예: 새 PC에 D 드라이브가 없음)

| 무엇 | 어떻게 |
| --- | --- |
| 데이터 폴더 | 아무 곳이나 괜찮습니다. 처음 실행할 때 고르거나, **설정 › 다른 폴더 열기**로 바꿉니다. |
| 코드 폴더 | **프로그램 · 배포** › `프로그램 · 코드`에서 오른쪽 클릭 › **설정 고치기** → 코드 폴더·빌드 폴더를 새 위치로. 버전 기록은 그대로입니다. |
| 새 프로그램의 기본 코드 위치 | 설정 파일의 `SourceRoot` (① 프로그램 등록을 하면 고른 폴더로 자동으로 바뀝니다) |
| 배포본 보관소·자동 백업 폴더 | NAS 경로라서 그대로 둡니다 (**설정** 화면에서 확인). |
| 업무 카드의 **링크** 첨부 | 원본 위치만 적어 둔 것이라 그 경로가 새 PC에서도 보여야 열립니다. **복사** 첨부는 데이터 폴더 안에 있어 같이 옮겨집니다. |

### 2.4 옮긴 뒤 확인

- [ ] 대시보드의 업무 수가 예전과 같다
- [ ] 업무 카드를 하나 열어 첨부 사진이 열린다
- [ ] 프로그램 · 배포 › 설치 현황이 예전과 같다
- [ ] 프로그램 · 코드 보기의 코드 상태가 ✔ 깨끗함이다
- [ ] 설정 화면의 배포본 보관소·자동 백업 폴더가 NAS 경로다
- [ ] **도움말** 화면이 열린다 (안 열리면 프로그램 폴더의 `Help` 폴더가 빠진 것)

## 3. 코드를 복사하지 않고 NAS에서 받기

코드 폴더를 복사하지 않았거나, 다른 PC에서 잠깐 작업할 때.

1. 새 PC에서 TS WorkBench를 **먼저 한 번 켭니다** (데이터 폴더를 고른 상태). NAS 코드 저장소를 믿을 곳으로 등록합니다. 이걸 안 하면 VS2022가 "dubious ownership" 오류를 냅니다.
2. VS2022 › **Git › 리포지토리 복제**
   - 리포지토리 위치: `\\10.101.0.80\ts팀\박종부\TSWork\Git\STRIP_LineScan.git` (프로그램 · 코드 보기의 NAS 백업 칸에 있는 경로)
   - 경로: 예전 코드 폴더 경로 (예: `D:\박종부\00.Source\01.대덕전자\01.STRIP\01.LineScan\LineScan`)
3. **복제** → 끝나면 VS2022에서 **Release로 빌드**합니다 (NAS에는 빌드 결과(bin)가 없습니다).
4. 경로가 예전과 다르면 TS WorkBench에서 **설정 고치기**로 코드 폴더를 바꿉니다.

> NAS에는 **커밋한 것만** 있습니다. 커밋하지 않은 변경은 옮겨지지 않으니, 옮기기 전에 꼭 커밋하세요.

## 4. 평소 백업 (자동으로 되는 것과 내가 할 것)

| 무엇 | 언제 | 어디로 | 들어가는 것 |
| --- | --- | --- | --- |
| 업무 기록 자동 백업 | 프로그램을 켤 때 하루 한 번 (설정 › **지금 백업**으로 바로) | NAS `…\TSWork\Backups\TSWorkData_날짜.zip` | 설정, 기준 정보, 프로그램 목록, 모든 업무 카드, 버전·설치 기록, 보고서 양식 |
| 코드 백업 | 프로그램을 켤 때, ①·②·과거 버전 가져오기 할 때, **NAS 코드 백업** 버튼 | NAS `…\TSWork\Git` | **커밋한** 코드와 버전 이름표 |
| 배포본 | ② 새 버전 배포 할 때 | NAS `…\TSWork\Releases` | 실행 파일 zip, 소스 zip, 매뉴얼, 변경 내역 |

**자동 백업에 들어가지 않는 것**: 업무 카드의 첨부 파일(`files\`), 만들어 둔 보고서 파일(`Reports\`, 현장 보고서 html). 용량이 커서 뺐습니다.

그래서 내가 할 일은 두 가지뿐입니다.

1. 코드는 **자주 커밋**하기 (커밋해야 NAS로 올라갑니다).
2. 한 달에 한 번 **데이터 폴더를 통째로 NAS에 복사**하기 — 첨부 사진·보고서까지 지키려면.
   - 예: `D:\박종부\TS업무` → `\\10.101.0.80\ts팀\박종부\TSWork\Data\2026-10`

## 5. PC가 고장 났을 때 (복구)

1. 새 PC에 VS2022와 TS WorkBench 프로그램 폴더를 준비합니다 (2.2의 1~3).
2. **업무 데이터**
   - 4장의 월 1회 통째 복사본이 있으면 그 폴더를 `D:\박종부\TS업무`로 복사합니다.
   - 없으면 NAS `…\TSWork\Backups`의 가장 최근 `TSWorkData_날짜.zip`을 빈 폴더에 풀고, 그 폴더를 데이터 폴더로 고릅니다. (첨부 파일은 빠져 있습니다)
3. **코드**: 3장처럼 NAS에서 받습니다.
4. **배포본·설치 기록**: 배포본은 NAS에 그대로 있고, 버전·설치 기록은 2의 데이터에 들어 있습니다.

## 6. 자주 묻는 것

**Q. 회사 PC와 집 PC에서 번갈아 써도 되나요?**
데이터 폴더를 NAS에 두고 두 PC에서 같은 폴더를 열면 됩니다. 단, 두 PC에서 **동시에** 켜 두고 같은 업무 카드를 고치면 나중에 저장한 쪽만 남습니다. 한쪽을 끄고 쓰세요.

**Q. 자동 백업 zip만 있으면 충분한가요?**
업무 카드 글과 기록은 모두 들어 있지만 **첨부 파일은 없습니다**. 사진·로그까지 남기려면 4장의 월 1회 통째 복사를 하세요.

**Q. 프로그램(TS WorkBench)을 새 버전으로 바꾸면 데이터는요?**
데이터는 데이터 폴더에 따로 있으므로 프로그램 폴더만 바꾸면 됩니다. 데이터 폴더는 건드리지 마세요.

**Q. 다른 회사에서 새로 시작하려면?**
새 빈 폴더를 데이터 폴더로 고르고, 설정 화면에서 회사·이름·기준 정보만 바꾸면 됩니다. 예전 데이터 폴더는 보관용으로 남겨 두세요.
