## 현상
2라인 노칭 2호기 OCR 검사에서 정상 셀을 NG로 판정하는 비율이 증가.
평소 0.1% → 10/12 야간조부터 2.3%. 같은 라인 1호기는 정상.

- 발생 시점·빈도: 10/12 야간조(22시)부터 지속, 시간당 약 40건
- 재현 조건: 2호기에서만 발생. 같은 셀을 1호기로 돌리면 OK. 검사 이미지가 전체적으로 어둡고 문자 가장자리가 흐림.
- 영향: NG 셀 재검 작업으로 라인 속도 80% 운전. 불량 유출은 없음.

## 원인
OCR 조명(바 조명 2개 중 우측) 밝기 열화. 사용 시간 약 21,000시간.

**근거**
1) 조명 컨트롤러 출력은 정상(설정 180)인데 측정 휘도가 좌측 대비 62%
2) 우측 조명을 1호기 예비품으로 임시 교체하자 NG 비율 0.1%로 즉시 복귀
3) 5 Why: 오판정 ← 이미지 어두움 ← 우측 조명 휘도 저하 ← LED 수명 ← 교체 주기 관리 없음

## 조치

**검증 결과**
교체 후 3시간(약 9,000셀) 생산 동안 NG 비율 0.08%. 오판정 이미지 0건. 고객 입회 확인 완료.

**재발 방지**
1) 조명 사용 시간 15,000시간 도달 시 교체하도록 정기 점검 체크리스트에 추가
2) 같은 시기 설치된 1라인·3라인 조명 휘도 측정 → 정기 점검 때 확인

**고객 전달 사항**
